# WebUI 索引构建参数配置 - 快速开始

## 🎉 新功能

WebUI 现在支持在创建数据集时完整配置所有索引构建参数！不再需要手动编辑 YAML 配置文件。

## 🚀 快速上手

### 1. 迁移数据库（如果你已安装旧版本）

```bash
uv run python scripts/migrate_queue_schema.py
```

### 2. 启动 WebUI

```bash
uv run scripts/start_webui.py
```

### 3. 创建数据集并配置参数

1. 访问 http://localhost:8501
2. 点击左侧"数据集"
3. 点击"创建新数据集"
4. 填写数据集信息
5. 选择配置预设：
   - **default**：平衡的通用配置
   - **fast**：快速处理，精度略低
   - **accurate**：高精度，处理稍慢
   - **mobile**：适合移动设备拍摄的图像

6. 配置计算资源：
   - **CPU 模式**：设置并行进程数（1-16）
   - **GPU 模式**：设置 GPU 数量（> 0）

7. （可选）展开"高级参数"自定义配置：
   - 特征提取参数
   - OCR 引擎设置
   - 索引类型和参数
   - 匹配策略

8. 点击"创建数据集"

## 📋 主要配置项

### 配置预设
快速选择最佳实践配置，适合大多数场景。

### 计算资源
- **并行进程数**：CPU 多进程并行度（推荐设置为 CPU 核心数的 50-75%）
- **GPU 数量**：使用的 GPU 卡数（0 表示仅使用 CPU）

### 特征提取
- **图像尺寸**：224（默认）/ 256 / 384
- **批处理大小**：8-256（GPU 模式建议 64-128，CPU 模式建议 8-32）

### OCR 引擎
- **引擎类型**：paddleocr（推荐）/ easyocr / tesseract
- **检测阈值**：0.0-1.0（默认 0.3）
- **识别阈值**：0.0-1.0（默认 0.5）

### 索引类型
- **Flat**：精确搜索（小数据集 < 10k）
- **IVFFlat**：倒排文件 + 精确（中等数据集 10k-100k）
- **IVFPQ**：倒排文件 + 乘积量化（大数据集 > 100k）
- **HNSW**：分层可导航小世界图（高性能）

### 匹配策略
- **权重配置**：图像、OCR、检测结果的权重分配（总和必须为 1.0）
- **相似度阈值**：各类特征匹配的最低阈值

## 💡 推荐配置

### 小型数据集（< 1000 图像）
```
配置预设: fast
并行进程数: 4
GPU 数量: 0
索引类型: Flat
```

### 中型数据集 + GPU（1000-50000 图像）
```
配置预设: default
GPU 数量: 1
批处理大小: 64
索引类型: IVFFlat
聚类中心数: 200
```

### 大型数据集 + 多 GPU（> 50000 图像）
```
配置预设: accurate
GPU 数量: 2
批处理大小: 128
索引类型: IVFPQ
聚类中心数: 400
```

### 高精度 OCR 需求
```
配置预设: accurate
OCR 引擎: paddleocr
检测阈值: 0.2
识别阈值: 0.6
OCR 权重: 0.4
```

## 🔧 故障排查

### GPU 模式不工作
安装 GPU 版本依赖：
```bash
pip install -r requirements-linux-gpu.txt
```

### 内存不足
1. 降低并行进程数
2. 减小批处理大小
3. 考虑使用 GPU 模式

### 索引构建失败
1. 检查聚类中心数是否过大
2. 确认 PQ 子向量数能整除特征维度
3. 验证图像路径是否正确
