# 数据集索引配置更新说明

## 📋 更新概述

**更新日期**：2026-09-12

**主要变更**：
1. ✅ 移除创建数据集表单中的匹配检索参数
2. ✅ 添加索引构建配置参数显示到数据集详情页

---

## 🎯 更新目标

### 问题分析

**之前的问题**：
- 创建数据集时混合了索引构建参数和匹配检索参数
- 匹配参数应该在搜索时配置，不应在创建数据集时配置
- 无法查看数据集使用了什么索引构建配置

**解决方案**：
- 创建数据集表单只保留索引构建相关参数
- 在数据集详情页显示索引构建配置信息
- 支持查看历史构建任务的配置参数

---

## 🔧 技术实现

### 1. 移除匹配参数（database_ui.py）

**移除的参数**：
- ❌ 精确匹配参数
  - `enable_exact`: 启用精确匹配
  - `max_hash_distance`: 最大哈希距离
- ❌ 内容匹配参数
  - `enable_content`: 启用内容匹配
  - `text_sim_threshold`: 文本相似度阈值
  - `top_k_stage1`: 第一阶段候选数
  - `scoring_threshold`: 综合评分阈值
  - `final_top_k`: 最终返回数量

**新增的参数**：
- ✅ 向量索引配置
  - `index_type`: 索引类型（Flat/IVFFlat/IVFPQ/HNSW）
  - `nlist`: 聚类数（IVFFlat/IVFPQ）
  - `m_hnsw`: 图连接数（HNSW）

**代码变更**：
```python
# 之前：混合了索引和匹配参数
with st.expander("**匹配参数**", expanded=False):
    # 精确匹配、内容匹配参数...

# 现在：只有索引构建参数
with st.expander("**索引构建配置**", expanded=False):
    # 向量索引类型配置...
```

---

### 2. 添加配置显示（details.py）

**显示内容**：

#### 2.1 配置概览（指标卡片）
- CPU 工作线程数
- GPU 数量
- 配置预设

#### 2.2 详细配置（可展开）
- 完整的 config YAML
- 任务元信息
  - 任务 ID
  - 状态
  - 创建/开始/完成时间
  - 当前阶段

**数据来源**：
- 从全局任务队列 `task_queue` 表读取
- 查询最近一次 `index_build` 类型的任务
- 读取 `config_yaml` 字段获取完整配置

**代码实现**：
```python
from qsearch.tasks.queue import TaskQueue, TaskKind

queue = TaskQueue(databases_root / ".tasks")
tasks = queue.list_tasks(
    database_name=selected_db,
    kind=TaskKind.INDEX_BUILD,
    limit=1
)

if tasks:
    task = tasks[0]
    # 显示配置信息...
```

## 📊 数据库字段说明

### task_queue 表相关字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `num_workers` | INTEGER | CPU 工作线程数（NULL = 自动） |
| `num_gpus` | INTEGER | GPU 数量（默认 0） |
| `config_preset` | TEXT | 配置预设名称 |
| `config_yaml` | TEXT | 完整的配置 YAML 文本 |
| `created_at` | TEXT | 任务创建时间 |
| `started_at` | TEXT | 任务开始时间 |
| `completed_at` | TEXT | 任务完成时间 |
| `stage` | TEXT | 当前执行阶段 |
| `status` | TEXT | 任务状态 |

## 🔄 向后兼容性

### 旧任务处理

**场景**：数据库迁移前创建的索引任务

**处理方式**：
- `num_workers` 字段为 NULL → 显示为"自动"
- `config_yaml` 字段为 NULL → 显示"使用默认配置"
- 无匹配的任务记录 → 显示"尚未构建过索引"

**兼容性保证**：
- ✅ 不会因为字段缺失而报错
