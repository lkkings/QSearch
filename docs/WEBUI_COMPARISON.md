## 主要改进

### 1️⃣ 简化导航

| 项目 | 更新前 | 更新后 |
|------|--------|--------|
| 导航页面 | 4 个（主页、搜索、标注、详情） | 1 个（仅主页） |
| 用户体验 | 需要在多个页面间切换 | 所有功能集中在一个页面 |
| 界面复杂度 | 较复杂 | 简洁清晰 |

## 技术实现

### 新增模块

```python
# src/qsearch/webui/system_monitor.py

def get_system_resources() -> Dict:
    """获取系统资源信息"""
    - CPU 使用率和核心数
    - 内存使用率和容量
    - GPU 信息（如果可用）
    
def get_gpu_info() -> Optional[Dict]:
    """获取 GPU 信息（优雅降级）"""
    - 自动检测 GPU 可用性
    - GPUtil 未安装时返回 None
    
def format_memory_size(size_gb: float) -> str:
    """格式化内存大小显示"""
    
def get_cpu_status_color(percent: float) -> str:
    """根据使用率返回状态颜色"""
```

## 使用场景对比

### 场景 1: 检查任务状态

**更新前**:
1. 查看"排队中"和"运行中"
2. 如果有失败，会显示警告
3. ❌ 不知道成功了多少任务

**更新后**:
1. 一眼看到 4 个指标
2. ✅ 清楚知道成功/失败的任务数
3. ✅ 可以计算成功率（120/123 = 97.5%）

### 场景 2: 监控系统负载

**更新前**:
- ❌ 无法在 WebUI 中查看系统资源
- 需要打开任务管理器或 `nvidia-smi`

**更新后**:
- ✅ 直接在侧边栏查看实时资源使用
- ✅ 颜色编码提醒资源紧张
- ✅ GPU 温度监控防止过热

### 场景 3: 页面导航

**更新前**:
- 需要在 4 个页面间切换
- 可能不清楚每个页面的功能

**更新后**:
- 所有功能集中在主页
- 更简洁、更直观

## 兼容性说明

### GPU 监控
- ✅ **有 NVIDIA GPU**: 完整显示 GPU 信息
- ✅ **无 GPU / AMD GPU**: 显示"GPU 信息不可用"
- ✅ **GPUtil 未安装**: 优雅降级，不影响其他功能

### 操作系统
- ✅ **Windows**: 完全支持
- ✅ **Linux**: 完全支持
- ✅ **macOS**: 支持（GPU 监控除外）
