# 索引构建配置功能说明

## 概述

在数据集详情页面新增了索引构建配置的加载、显示和修改功能，允许用户查看历史配置并在构建/重建索引时自定义参数。

## 新增文件

### 1. `src/qsearch/webui/config_editor.py`

配置编辑器组件，提供以下功能：

- **加载配置**
  - `load_default_config()`: 加载默认配置（`config/features.yaml`）

- **UI 渲染**
  - `render_config_form()`: 渲染配置编辑表单
  - `display_task_config()`: 显示任务的配置信息（只读）

## 功能特性

### 1. 查看当前配置（只读）

在"查看当前配置"标签页中：

- 显示最近一次索引构建任务的配置参数
- 硬件配置：CPU 工作线程数、GPU 数量
- 索引配置：显示是使用默认配置还是自定义配置
- 完整配置 YAML（自定义配置时可展开查看）
- 任务元信息：任务ID、状态、时间戳等

### 2. 修改配置

在"修改配置"标签页中：

#### 硬件配置

- **CPU 工作线程数**: 1-32，默认 4
  - 建议设置为 CPU 核心数的 50-75%
  
- **GPU 数量**: 0-8，默认 0
  - 设置为 0 表示仅使用 CPU
  - > 0 时将使用 GPU 加速

#### 索引配置

提供 2 种配置方式：

1. **使用默认配置**（默认）
   - 使用 `config/features.yaml` 中的配置
   - 适合大多数场景
   - 可展开查看配置详情

2. **使用自定义配置**
   - 勾选"使用自定义配置"复选框
   - 提供 YAML 文本编辑器
   - 自动加载当前配置或默认配置作为编辑起点
   - 实时验证 YAML 格式
   - 可预览关键参数

### 3. 应用配置并构建索引

- 点击"建立索引"（未建立）或"重建索引"（已建立）按钮
- 使用表单中设置的所有参数创建索引构建任务
- 任务入队后显示任务 ID
- 可在主页"任务监控"标签查看进度

## 修改的文件

- 替换原有的简单配置显示为标签页界面

## 使用流程

### 首次建立索引（使用默认配置）

1. 打开数据集详情页
2. 找到"索引构建配置"部分
3. 切换到"修改配置"标签页
4. 配置硬件参数（CPU/GPU）
5. 保持"使用默认配置"不勾选
6. 点击"建立索引（使用上述配置）"
7. 等待任务完成

### 使用自定义配置

1. 打开数据集详情页
2. 切换到"修改配置"标签页
3. 勾选"使用自定义配置"
4. 编辑 YAML 配置
5. 确认 YAML 格式有效（显示绿色勾号）
6. 点击"建立/重建索引"

### 修改配置并重建

1. 打开数据集详情页
2. 在"查看当前配置"标签查看现有配置
3. 切换到"修改配置"标签页
4. 调整参数或编辑配置
5. 点击"重建索引（使用上述配置）"
6. 确认重建（会覆盖现有索引）

## 技术实现

### 配置加载流程

```
1. 加载默认配置 (features.yaml)
2. 如果勾选自定义配置，使用编辑器中的 YAML
3. 否则使用默认配置
4. 序列化为字符串存入任务队列（仅自定义配置时）
```

### 配置存储

- 配置保存在任务队列的 `config_yaml` 字段
- `config_yaml`: 完整配置 YAML 字符串（仅在使用自定义配置时保存）
- 硬件参数单独存储：`num_workers`、`num_gpus`

### 配置显示

- 查询数据库最近的 `INDEX_BUILD` 类型任务
- 从任务记录中提取配置参数
- 使用 `ConfigEditor.display_task_config()` 渲染只读视图
