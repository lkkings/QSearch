# 索引构建配置 - 快速入门

## 访问配置界面

1. 启动 WebUI：`python scripts/start_webui.py`
2. 在主页选择一个数据集
3. 点击"详情"进入数据集详情页
4. 滚动到"索引构建配置"部分

## 场景 1：首次建立索引（使用默认配置）

**适合**: 大多数用户，首次使用

### 步骤

1. 在"索引构建配置"部分，切换到**"修改配置"**标签页

2. **硬件配置**（根据你的机器调整）：
   - CPU 工作线程：`4`（如果你有 8 核 CPU）
   - GPU 数量：`0`（如果没有 GPU）或 `1`（有 GPU）

3. **索引配置**：
   - 保持"使用自定义配置"**不勾选**（使用默认配置）

4. 点击**"建立索引（使用上述配置）"**

5. 等待任务完成（在主页"任务监控"标签查看进度）

### 预期结果

- 索引构建时间：约 5-10 分钟（取决于图像数量和硬件）
- 使用 `config/features.yaml` 中定义的默认参数

---

## 场景 2：使用自定义配置

**适合**: 需要调整索引参数，如索引类型、模型选择等

### 步骤

1. 切换到**"修改配置"**标签页

2. **硬件配置**：保持默认或根据需要调整

3. **索引配置**：
   - 勾选"**使用自定义配置**"

4. 编辑 YAML 配置，例如：
   ```yaml
   # 修改索引类型
   index:
     type: HNSW  # 从 Flat 改为 HNSW（更快的检索）
     hnsw_m: 16
     ef_construction: 40
     ef_search: 32
   ```

5. 确认底部显示"✓ YAML 格式有效"

6. 点击**"建立索引（使用上述配置）"**

### 预期结果

- 使用自定义参数构建索引
- 配置 YAML 保存在任务记录中
- 可在"查看当前配置"中看到完整自定义配置

---

## 场景 3：查看历史配置

**适合**: 想了解当前索引是用什么参数构建的

### 步骤

1. 在"索引构建配置"部分，停留在**"查看当前配置"**标签页

2. 查看配置概览：
   - CPU 工作线程
   - GPU 数量
   - 配置类型（默认/自定义）

3. 如果是自定义配置，点击"查看完整配置 YAML"展开详细配置

4. 查看任务信息：
   - 任务 ID
   - 状态（已完成/失败/运行中）
   - 创建/开始/完成时间

### 预期结果

- 了解当前索引的配置参数
- 决定是否需要用不同配置重建

---

## 场景 4：重建索引（换配置）

**适合**: 对当前索引效果不满意，想尝试不同配置

### 步骤

1. 先在**"查看当前配置"**标签查看现有配置

2. 切换到**"修改配置"**标签页

3. 修改配置：
   - 调整硬件参数
   - 或勾选"使用自定义配置"编辑 YAML

4. 点击**"重建索引（使用上述配置）"**

5. 确认操作（会覆盖现有索引）

6. 等待重建完成

### 预期结果

- 旧索引被覆盖
- 使用新配置构建索引
- 索引行为根据新配置调整

## 配置选择指南

### 何时使用默认配置？

- ✅ 首次使用，不确定如何配置
- ✅ 对配置参数不熟悉
- ✅ 默认配置已经满足需求

### 何时使用自定义配置？

- ✅ 需要调整索引类型（Flat/IVFFlat/IVFPQ/HNSW）
- ✅ 需要更换模型（文本编码模型、图像特征模型）
- ✅ 需要调整匹配阈值和策略
- ✅ 有特定的性能或精度需求

### 常见自定义场景

#### 1. 更快的检索速度

```yaml
index:
  type: HNSW  # 使用 HNSW 索引
  hnsw_m: 16
  ef_construction: 40
  ef_search: 32
```

#### 2. 更低的内存占用

```yaml
index:
  type: IVFPQ  # 使用 IVFPQ（压缩索引）
  nlist: 100
  nprobe: 10
  m_pq: 16
  nbits: 8
```

#### 3. 调整匹配阈值

```yaml
matching:
  content_match:
    stage1:
      text_similarity_threshold: 0.80  # 调整相似度阈值
      top_k: 150  # 调整候选数量
    scoring:
      threshold: 0.85  # 调整最终分数阈值
```

## 硬件配置建议

### CPU 工作线程数

- 4 核 CPU：设置为 `2-3`
- 8 核 CPU：设置为 `4-6`
- 16 核 CPU：设置为 `8-12`
- 一般设置为核心数的 50-75%

### GPU 数量

- 无 GPU：设置为 `0`
- 有 1 块 GPU（如 RTX 3060）：设置为 `1`
- 多 GPU：设置为实际可用 GPU 数

注意：使用 GPU 会显著加速索引构建，但需要足够的显存（建议 >= 6GB）

## 常见问题

### Q1: 改了配置后需要重建索引吗？

**A**: 是的。配置参数影响索引的构建方式，修改配置后必须重建索引才能生效。

### Q2: 重建索引会丢失数据吗？

**A**: 不会。重建索引只影响索引文件，不会删除原始图像或标注数据。

### Q3: 默认配置和自定义配置哪个更好？

**A**: 没有绝对的"更好"。默认配置适合大多数场景，如果你有特定需求（如更快的检索、更低的内存占用），可以使用自定义配置。

### Q4: 自定义配置会保存吗？

**A**: 是的。自定义配置 YAML 会保存在任务记录中，可以在"查看当前配置"中查看。

### Q5: YAML 格式错误怎么办？

**A**: 编辑器会实时验证 YAML 格式，如果显示"✗ YAML 格式错误"，请检查：
- 缩进是否正确（使用空格，不要用制表符）
- 冒号后是否有空格
- 引号是否配对
- 是否有语法错误
