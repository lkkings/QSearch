## Purpose

定义检索的提交与呈现方式：单图查询给出即时结果、批量检索转入后台，以及按标注进度筛选已有 Query 以便找出还没人看过的那些。

## ADDED Requirements

### Requirement: 单图查询给出即时结果

系统 SHALL 支持提交单张图像并在同一交互流程内呈现结果。用户 MUST NOT 需要离开当前页面去别处查看这次查询的结果。

#### Scenario: 提交并得到结果

- **WHEN** 用户提交一张查询图像
- **THEN** 系统在当前页面呈现该次检索的完全匹配与内容匹配结果

#### Scenario: 查询失败

- **WHEN** 一次单图查询失败
- **THEN** 系统在当前页面呈现可读的失败原因

### Requirement: 单图查询支持三种输入方式

系统 SHALL 支持以上传文件、本地文件路径、图像 URL 三种方式提供查询图像。对无效输入 MUST 在提交前给出提示。

#### Scenario: 本地路径不存在

- **WHEN** 用户输入的本地文件路径不存在
- **THEN** 系统提示文件不存在，且不允许提交

### Requirement: 成功的单图查询进入标注列表

每次成功的单图查询 SHALL 进入该数据集的标注列表。用户 MUST 能在标注界面找到该 Query 及其候选，无需额外操作。

#### Scenario: 查询成功后可标注

- **WHEN** 一次单图查询成功完成
- **THEN** 该 Query 出现在标注列表中
- **AND** 其候选可被标注

#### Scenario: 查询失败不进入列表

- **WHEN** 一次单图查询失败
- **THEN** 标注列表中不出现该 Query 的条目

### Requirement: 未建索引的数据集不可检索

当目标数据集尚未构建索引时，系统 SHALL 阻止提交检索并说明原因。系统 MUST NOT 让用户等待一次注定失败的检索。

#### Scenario: 对未建索引的数据集提交

- **WHEN** 用户选择的数据集尚未构建索引
- **THEN** 提交被阻止
- **AND** 系统提示需先构建索引，并指出可在任务监控查看构建进度

### Requirement: 批量检索转入后台

系统 SHALL 支持以文件夹或文件列表提交批量检索，并将其作为后台任务执行。提交后 MUST 告知任务已受理及可在何处查看进度。

#### Scenario: 提交批量检索

- **WHEN** 用户提交一个含多张图像的批量检索
- **THEN** 系统受理该任务并提示可在任务监控查看进度
- **AND** 当前页面保持可交互

#### Scenario: 空批量不予受理

- **WHEN** 用户提交的批量输入未包含任何有效图像
- **THEN** 提交被阻止并给出提示

### Requirement: 按标注进度筛选 Query

系统 SHALL 支持按标注进度筛选某数据集内的 Query，至少提供以下条件：一个候选都未标注、部分候选已标注、已标注但无任何命中、没有任何候选。筛选 MUST 只依据属于当前结果集的候选。

#### Scenario: 筛选完全未标注的 Query

- **WHEN** 用户选择「一个候选都未标注」
- **THEN** 结果只含当前结果集内没有任何候选被标注的 Query

#### Scenario: 筛选部分标注的 Query

- **WHEN** 用户选择「部分候选已标注」
- **THEN** 结果只含已有标注但仍有候选未标注的 Query

#### Scenario: 筛选无命中的 Query

- **WHEN** 用户选择「已标注但无任何命中」
- **THEN** 结果只含已有标注且其中没有任何命中的 Query

#### Scenario: 筛选无候选的 Query

- **WHEN** 用户选择「没有任何候选」
- **THEN** 结果只含当前结果集内没有候选的 Query

#### Scenario: 筛选无结果

- **WHEN** 所选条件下没有匹配的 Query
- **THEN** 系统给出明确的空结果提示，而非空白区域

### Requirement: 从筛选结果进入标注

系统 SHALL 允许从筛选结果直接进入某个 Query 的标注界面，并 MUST 保留所选数据集与该 Query 的上下文。

#### Scenario: 点选筛选结果中的 Query

- **WHEN** 用户在筛选结果中选择一个 Query
- **THEN** 系统进入该 Query 的标注界面
- **AND** 无需重新选择数据集
