## Purpose

定义标注数据的身份与保全规则：标注条目由 Query 图路径与 Match 图路径唯一确定，重复检索同一张图不产生重复条目，也不抹掉已经做出的人工判断。

## ADDED Requirements

### Requirement: 查询由数据集与 Query 图路径唯一确定

在同一数据集内，一条查询记录 SHALL 由其 Query 图像路径唯一确定。对同一张 Query 图重复检索 MUST NOT 产生第二条查询记录。

#### Scenario: 重复检索同一张图

- **WHEN** 用户对某数据集中同一张 Query 图先后检索两次
- **THEN** 标注列表中该 Query 只出现一条记录

#### Scenario: 不同数据集的同名路径

- **WHEN** 两个数据集各有一次针对相同 Query 图路径的检索
- **THEN** 两个数据集各自保有一条独立的查询记录

### Requirement: 候选由查询与 Match 图路径唯一确定

在一条查询之内，一个候选 SHALL 由其 Match 图像路径唯一确定。同一 Match 图 MUST NOT 在同一查询下出现两个候选条目。

#### Scenario: 重搜产出相同的 Match 图

- **WHEN** 重复检索后某 Match 图再次出现在结果中
- **THEN** 该 Match 图在此查询下仍只有一个候选条目

### Requirement: 重搜不覆盖人工标注

重复检索 SHALL 更新候选的机器输出，包括排名、匹配类型、置信等级与各项评分。候选的人工标注、备注与标注时间 MUST NOT 被覆盖或清除。

#### Scenario: 已标注候选被重新命中

- **WHEN** 一个已标注为命中的候选在重搜后仍出现在结果中且评分变化
- **THEN** 该候选的评分与排名被更新
- **AND** 其标注仍为命中，备注与标注时间不变

#### Scenario: 重搜产生新候选

- **WHEN** 重搜结果中出现此前没有的 Match 图
- **THEN** 该候选被加入，且标注为未标注

### Requirement: 掉出结果集的候选被保留并标记

当重复检索后某候选不再出现在结果中时，系统 SHALL 保留该候选及其人工标注，并标记其不属于当前结果集。系统 MUST NOT 因其掉出结果集而删除它。

#### Scenario: 已标注候选掉出结果集

- **WHEN** 一个已标注的候选在重搜后不再出现在结果中
- **THEN** 该候选及其标注被保留
- **AND** 该候选被标记为不属于当前结果集

#### Scenario: 掉出后又重新命中

- **WHEN** 一个被标记为不属于当前结果集的候选在下一次重搜中再次出现
- **THEN** 该标记被清除，候选恢复为属于当前结果集
- **AND** 其原有人工标注保持不变

### Requirement: 标注列表默认只呈现当前结果集

标注界面 SHALL 默认只呈现属于当前结果集的候选。系统 MUST 提供开关以一并查看不属于当前结果集的历史候选。

#### Scenario: 默认视图

- **WHEN** 用户打开某查询的标注界面
- **THEN** 只呈现属于当前结果集的候选

#### Scenario: 查看历史候选

- **WHEN** 用户开启查看历史候选
- **THEN** 不属于当前结果集的候选一并呈现，并可辨识其历史身份

### Requirement: 查询标注进度不受历史候选影响

查询的标注进度 SHALL 只依据属于当前结果集的候选计算。不属于当前结果集的候选 MUST NOT 使查询停留在未完成状态。

#### Scenario: 历史候选未标注

- **WHEN** 某查询当前结果集内的候选已全部标注
- **AND** 存在一个未标注且不属于当前结果集的候选
- **THEN** 该查询的标注进度为已完成

### Requirement: 已有标注库可迁移到新身份约束

系统 SHALL 提供迁移能力，把既有标注库收敛到唯一身份约束下。迁移 MUST 合并指向同一数据集与同一 Query 图路径的多条查询记录，MUST 保留人工标注，并 MUST 支持先输出报告而不改动数据。

#### Scenario: 合并重复查询

- **WHEN** 迁移遇到同一数据集下多条指向相同 Query 图路径的记录
- **THEN** 这些记录被合并为一条
- **AND** 各条下的候选按 Match 图路径归并到该条之下

#### Scenario: 标注冲突取最新

- **WHEN** 被合并的多个候选指向同一 Match 图且带有不同的人工标注
- **THEN** 保留标注时间最新的那个非空标注

#### Scenario: 先出报告

- **WHEN** 用户以报告模式运行迁移
- **THEN** 系统输出将合并的分组数与存在标注冲突的条目数
- **AND** 不修改任何数据

#### Scenario: 重复执行不产生额外影响

- **WHEN** 迁移在已完成迁移的库上再次执行
- **THEN** 数据不发生变化
